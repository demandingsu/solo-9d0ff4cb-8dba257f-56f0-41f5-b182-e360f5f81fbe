# 冷却水站班次水量平衡诊断

计量员每班登记各管段水表读数，接口自动核对全网水量是否账平；
账不平则指出“只错一只表”的嫌疑水表及该管段的可行水量范围，
并支持补登人工复测区间逐步定位失准表。

甲乙两区分别抄表的场景另提供**分区合报**：两区各自整份上传带符号读数，
按既有诊断号选定管网底图拼表——交界管段只算一次，取两区非负交集；
其余管段一区独报。拼表后复用同一套账平诊断，账不平也保存，
保存时任一区已换稿则整单退回。

## 快速开始

```bash
docker compose up --build
# 打开 http://localhost:8000/docs 直接操作全部接口
```

本地开发（无需 Docker）：

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --port 8000
```

## 规则与语义

- 每班一次登记至多 **20 个管段**，每段填：起点、终点、过水量上限、
  水表读数区间；水量一律为**非负整数升**。
- 除标记的**进出水口**外，每个节点流入量 = 流出量。
- 所有生效读数能同时成立 → **账平**，并给出一组可行流量。
- 否则逐一试算“仅忽略该表原读数”：能使全网账平的表列为**嫌疑表**，
  并给出该管段可行水量的**上下界**；一只都找不到则提示
  **单表误差无法解释**（可能多表失准或漏记管段）。
- **人工复测区间**：补登后**取代该表原读数**，且与过水量上限一样
  **始终有效**——即使诊断中忽略该表，复测区间也不被忽略；
  同一管段多次复测取交集。复测与由此产生的新诊断**同一事务生效**；
  计算或落库失败时不写库，原读数与诊断保持不变。
- 诊断与所用读数（含生效复测区间）存入 **SQLite**，按班次查询；
  重新登记读数不会清除历史诊断与该班已登记的复测区间。

## 甲乙分区合报

冷却水站由甲乙两区分别抄表，交界管段在全站底表里只能算一次。

- **底图选定**：用一次已有诊断的诊断号选定管网底图——管段编号、
  底图方向（起止节点）、过水量上限与进出水口均取自该诊断的输入。
- **分区上报**：`POST /zones/{zone}/submissions`（zone 取 `甲`/`乙`），
  每次上传或更正**整份**读数；每条填管段编号、**计量方向**的起止节点和
  **带符号整数升**区间（负值表示按计量方向反向过水）。更正即整份替换，
  旧版本保留，每次生成一个新**上报号**。
- **拼表规则**（合报请求中声明交界管段）：
  - 交界管段须**两区都报**，且端点与底图管段一致——同向（起止与底图相同）
    或反向抄表（起止与底图对调）均可；换到底图方向后取两区区间的
    **非负交集**，作为底表里的一条读数；
  - 其余管段须由**一区独报**，两区同报或两区都缺报均退回；
  - 带符号区间先按计量方向换算到底图方向（反向取相反数并交换上下界），
    再与非负半轴取交集；取不到非负区间、交界段无交集、管段或端点与底图
    不符、同区重复、底图中不存在的管段等问题**一次性列出**并退回（422，
    不写库）。
- **诊断与保存**：用拼好的底表读数、底图的过水量上限和进出水口跑原有
  账平诊断；**账不平也保存**（含嫌疑表与可行界）。
- **换稿防护**：合报请求锁定两区所用上报号；拼表和诊断期间两区仍可更正，
  保存时在同一事务内复查，任一区已有更新的上报号则返回 **409 退回**，
  不写库。
- **入库与查询**：底表、诊断结果与所用两个上报号同一事务入库；
  按底图（诊断号）查**最近一次成功合报**及全部历史；失败的合报不写库，
  此前的成功结果仍可按合报号查询。

合报示例（底图为 `IN→A→B→C→OUT`，S3 `B→C` 是甲乙交界，乙区反向抄表）：

```json
POST /zones/乙/submissions
{"readings": [
  {"segment_key": "S3", "from_node": "C", "to_node": "B",
   "meter_lo": -110, "meter_hi": -100},
  {"segment_key": "S4", "from_node": "OUT", "to_node": "C",
   "meter_lo": -110, "meter_hi": -100}
]}

POST /combined-reports
{"base_diagnosis_id": 6, "boundary_segment_keys": ["S3"],
 "jia_submission_id": 1, "yi_submission_id": 2}
```

乙区反向的 `[-110,-100]` 换到底图方向为 `[100,110]`；交界 S3 与甲区
`[100,110]` 取非负交集仍为 `[100,110]`，底表只保留一条 S3 读数。

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/shifts/{shift}/readings` | 登记（替换）该班管段读数并立即诊断 |
| POST | `/shifts/{shift}/remeasurements` | 补登复测区间，与新诊断一起生效 |
| GET | `/shifts/{shift}/diagnoses` | 该班历次诊断（含所用读数） |
| GET | `/shifts/{shift}/diagnoses/latest` | 该班最新诊断 |
| GET | `/shifts/{shift}/readings` | 该班当前登记与生效复测区间 |
| GET | `/shifts` | 已有登记的班次 |
| POST | `/zones/{zone}/submissions` | 甲/乙区整份上报或更正读数，返回上报号 |
| GET | `/zones/{zone}/submissions` | 该区全部上报版本（新的在前） |
| GET | `/zones/{zone}/submissions/latest` | 该区最新上报 |
| POST | `/combined-reports` | 按底图诊断号合报两区读数并诊断（换稿 409 退回） |
| GET | `/combined-reports/by-base/{base_diagnosis_id}` | 按底图查全部成功合报（含最近一次） |
| GET | `/combined-reports/{report_id}` | 按合报号查单次成功合报 |

登记示例：

```json
POST /shifts/一班/readings
{
  "ports": ["IN", "OUT"],
  "segments": [
    {"key": "S1", "from_node": "IN", "to_node": "A",
     "capacity": 1000, "meter_lo": 100, "meter_hi": 200},
    {"key": "S2", "from_node": "A", "to_node": "B",
     "capacity": 1000, "meter_lo": 100, "meter_hi": 200},
    {"key": "S3", "from_node": "B", "to_node": "OUT",
     "capacity": 1000, "meter_lo": 300, "meter_hi": 400}
  ]
}
```

守恒要求 S1=S2=S3，S3 的 [300,400] 与其余两只矛盾，返回账不平、
嫌疑表 S3、S3 可行水量 [100,200]。补登复测
`{"remeasures": [{"segment_key": "S3", "rlo": 150, "rhi": 150}]}`
后，复测值取代 S3 原读数，全网账平，可行流量 150/150/150。

## 实现要点

- 诊断建模为混合整数规划（HiGHS，经 `scipy.optimize.milp`）：
  节点-弧关联矩阵 + 整数流量变量 + 各区间约束，精确求解。
- 写路径均为“先算后写、单事务提交”：诊断在内存中算完，
  再把登记/复测与诊断结果放进同一 SQLite 事务；任一步失败整体回滚。
- 合报拼表在 `app/combine.py`：方向换算与非负交集为纯函数，
  全部校验问题收集齐再一次性退回；合报保存事务内复查两区最新上报号，
  与请求锁定的上报号不一致即回滚（`StaleSubmissionError` → 409）。
- SQLite 路径由 `DATABASE_PATH` 指定（默认 `data/app.db`，
  Compose 中挂卷 `/data` 持久化）。

## 测试

```bash
python3 tests/smoke.py http://127.0.0.1:8000           # 班次诊断冒烟（需服务已启动）
python3 tests/smoke_combine.py http://127.0.0.1:8000   # 分区合报冒烟（含反向抄表）

```

覆盖：跨节点矛盾定位单表、补登复测后账平、失败保留原诊断、
多表失准提示、复测协助定位、入参校验（>20 段/区间倒置/负数）、
按班次查询与持久化；合报侧覆盖反向抄表换算、交界非负交集、
缺报/同区重复/端点不符/无交集/取不到非负区间一次性列问题退回、
账不平也保存、按底图查最近成功合报、失败后原结果可查，
以及拼表诊断期间换稿在保存时退回。
